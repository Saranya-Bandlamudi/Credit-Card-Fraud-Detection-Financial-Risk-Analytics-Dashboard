# 💳 Credit Card Fraud Detection & Financial Risk Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing credit card transaction data to identify fraudulent activities, monitor financial risk, and generate actionable business insights. The solution combines SQL, Python, and Power BI to perform data cleaning, fraud analysis, KPI generation, and interactive dashboard development.

---

## 🎯 Project Objectives

- Detect fraudulent transaction patterns
- Analyze financial transaction behavior
- Monitor fraud and genuine transaction trends
- Generate risk-focused business insights
- Build an interactive Power BI dashboard for fraud monitoring
